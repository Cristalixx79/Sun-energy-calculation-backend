# Старый Jinja2-фронтенд (не используется)

Здесь сохранены страницы/стили из предыдущей версии проекта
(server-side rendering через Jinja2). Лабораторная №3 требует, чтобы
бэкенд был чистым REST/JSON API «для использования его в SPA» и
тестировался через Insomnia/Postman, а не через рендер HTML —
поэтому в `main.py` эти шаблоны больше не подключены.

Ничего не удалено, чтобы не потерять проделанную работу: если позже
понадобится собрать реальный SPA-фронтенд поверх нового API
(`/api/services/...`, `/api/users/...`), эти файлы — хорошая
отправная точка по разметке и стилям, но обращения к серверу нужно
будет переписать на `fetch`/`XMLHttpRequest` к JSON-эндпоинтам.
